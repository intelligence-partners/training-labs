# Politique de télétravail 2026
Les salariés en CDI peuvent télétravailler jusqu'à deux jours par semaine, après accord écrit de leur manager.
Le télétravail n'est pas possible pendant la période d'essai.
Une indemnité forfaitaire de 2,50 euros par jour télétravaillé est versée, dans la limite de 10 jours par mois.
Le salarié utilise obligatoirement le VPN de l'entreprise. Les demandes se font dans l'outil RH, rubrique Télétravail.
